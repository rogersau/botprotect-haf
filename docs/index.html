Two detectors. Your decision.

Protection on your terms.

Two protection detectors run quietly in the background. When something looks suspicious, your team gets a notification and a review page with the evidence.

01

Catches posts in a trap channel

Create a clearly marked “do not post” channel. Members who post there get flagged for your team to review.

02

Spots repeated messages

By default, it flags someone who sends the same message in five different channels within 60 seconds.

03

Keeps your team in control

Review the evidence and confirm or dismiss each flag. Optional message deletion works per protection.

Your team decides member actions. BotProtect never automatically bans, kicks, or times out members. Confirming a flag records your decision; any action against a member is taken in Discord. Message deletion runs automatically only when you enable it for a detector.

Your server. Your setup.

How to deploy.

Pick the hosting path that fits you. Each installation belongs to one Discord server and needs its own dedicated bot application.

Cloudflare Recommended

Let Cloudflare host it.

Setup happens in your browser and your computer doesn't need to stay on. You need a Cloudflare account, a GitHub account, and permission to manage your Discord server. The ongoing Discord connection uses compute even when the server is quiet; read the hosting notes before choosing a plan.

  1. Create a Discord application in the Developer Portal and enable Message Content Intent. Keep the bot token, Application ID, client secret, and your server ID handy.
  2. Click Deploy to Cloudflare and follow the prompts, entering those four values when asked.
  3. In your application's OAuth2 settings, add your new website address followed by /auth/callback as a redirect URL.
  4. Invite the bot to your server from its Installation page with the required permissions.
  5. Sign in, choose your channels and trusted roles in Protection settings, save, then select Start protection.

Docker Self-hosted

Run it on your own server.

Already have an always-on computer, NAS, or VPS? BotProtect runs as a Docker Compose stack with a persistent SQLite volume. No Cloudflare account required. Needs some technical setup.

# one container protects one Discord server
git clone https://github.com/rogersau/botprotect-haf.git
cd botprotect-haf
cp .env.example .env

Fill in .env with your Discord credentials. Register your PUBLIC_URL followed by /auth/callback as the application's OAuth2 redirect URL, and invite the bot to your server. Then start the container:

docker compose up -d --build --wait

Open http://localhost:3000 on the Docker host, sign in, save your protection settings, and select Start protection.
